# Decision records

Short records of significant decisions (ADRs). One file per decision, numbered:
`NNNN-short-title.md`. Copy [0000-template.md](0000-template.md) to start a new one.

Records are not edited after acceptance; a changed decision gets a new record that
supersedes the old one.
