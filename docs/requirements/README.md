# Requirements

One file per topic. Each file starts as a template: the questions to answer are the
headings, and each has a **Decision** line. The owner may edit these files directly;
whatever the owner writes is authoritative.

## Conventions

- `**Decision:** _TBD_` — not discussed yet.
- `**Decision:** _Open — see OQ-xxx_` — discussed, owner undecided; tracked in
  `../open-questions.md`.
- `**Decision:** <text>` — agreed.
- `**MVP:** yes / no / later` — added where scope is relevant.
